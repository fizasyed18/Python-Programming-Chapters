# **Introduction**

## **What is Python?**

Python is a high-level, general-purpose programming language known for its simple syntax and readability.

Python is widely used in:

- Data Analytics
- Artificial Intelligence
- Machine Learning
- Web Development
- Automation
- API Development
- Scientific Computing

## **Running Python**

Python programs can be written and executed using:

- VS Code
- PyCharm
- Jupyter Notebook
- Google Colab
- Python IDLE
- Command Line / Terminal

To check whether Python is installed:

python --version

Example:

Python 3.13.9

## **First Python Program**

print("Hello, World!")

## **Comments**

Comments are notes written inside the code for humans to understand.

Python ignores comments when executing the program.

Single-line comment
# This is a comment
print("Hello Python")

## **Python Indentation**

Python uses indentation to define blocks of code.

Example:

age = 20

![Indentation](indentation.png)

The indentation before print() is important.

Incorrect indentation can produce an error:

if age >= 18:

print("You are an adult")
